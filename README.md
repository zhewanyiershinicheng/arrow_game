# 一箭又一箭（Arrow Puzzle）

基于 Python + Pygame 的点击式箭头解谜小游戏。玩法参考休闲小游戏「一箭又一箭」的核心规则：观察箭头方向与阻挡关系，按合适顺序点击，使所有箭头依次飞出棋盘。

界面采用 **浅色** 风格：浅灰底、白卡片、蓝色强调、胶囊徽章。

---

## 环境要求

- Python 3.10+
- 依赖：`pygame` 或 `pygame-ce`（任选其一即可）

```bash
pip install pygame
# 或
pip install pygame-ce
```

Windows 可使用系统自带中文字体（微软雅黑）；无字体时会回退到 Pygame 默认字体。

## 运行

```bash
cd arrowgame
python arrow_game.py
```

可选环境变量：

| 变量 | 作用 |
|------|------|
| `ARROW_GAME_SILENT=1` | 完全静音 |
| `ARROW_GAME_ENABLE_SOUND=0` | 不初始化音频设备 |

音频素材在 `assets/sfx/`。若缺失，请检查文件。
## 玩法规则

1. 棋盘上有多支 **上 / 下 / 左 / 右** 箭头。  
2. 点击箭头后，检查其前进方向上、到棋盘边界之间是否还有其他箭头：  
   - **无阻挡**：飞出棋盘并消除；  
   - **有阻挡**：碰撞反馈（弹回、变色、提示），并消耗一次可失误次数。  
3. **可失误次数**：每关 3 次。次数减到 0 时**不会立刻失败**；**在已是 0 时再失误**，本关失败。  
4. 清空本关全部箭头 → 通关。  
5. 地图**每次随机生成**，并用逆序构造 + 求解器保证**一定有解**。  
6. 难度主要由**箭头数量**决定（剧情模式随关卡上升）。

## 游戏模式

### 剧情模式

- 共 **4 关**，随机地图  
- 箭头数量约：5 → 7 → 9 → 11  
- 全关通关后显示**星级评价**

| 星级 | 条件 |
|------|------|
| ★★★ | 全程 **0 次失误** |
| ★★ | 总失误 **≤ 4**，且**无失败重开** |
| ★ | 总失误 > 4，或存在失败重开 |

### 高难模式

- 仅 **1 关**，箭头**铺满棋盘**（5×5 = **25** 支）  
- **只计本关用时**，目标 **60 秒**以内  
- 进入前会弹出规则说明  

| 星级 | 条件 |
|------|------|
| ★★★ | **0 失误** 且 **用时 < 1 分钟** |
| ★★ | **失误 ≤ 3** 且 **用时 < 1 分钟** |
| ★ | 用时 ≥ 1 分钟 **或** 失误 > 3 |

## 操作

| 操作 | 说明 |
|------|------|
| 鼠标左键 | 点击箭头 / 按钮 |
| `R` | 重新开始（菜单为开始剧情；游戏中重开新图） |
| `M` | 静音 / 取消静音 |
| `Esc` | 返回菜单 |

游戏界面 HUD 显示：关卡、剩余箭头、可失误次数、计时（剧情为「本关 / 总用时」，高难为本关用时 + 60s 目标）。

## 设计要点

- **路径检测**：同一行 / 列上，箭头与边界之间是否仍有其他箭头。  
- **可解保证**：按消除顺序的**逆序**放置箭头，新放的箭头不得被「已放置（更晚消除）」的箭头挡住，再用求解器验证。  
- **失误语义**：3→0 可继续玩；0 之后再错才失败（便于观察动效与星级统计）。  
- **性能**：避免每帧创建整屏透明 Surface；粒子与尝试次数有上限；音频初始化限时，降低卡死风险。
